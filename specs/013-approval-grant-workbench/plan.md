# 实施计划：人工审批与 Grant 处置工作台

## 技术路径

1. 后端在 `build_console_snapshot` 的工作台聚合层补充 `approvalWorkbench`，从现有 `approvals` 事实生成只读摘要。
2. 前端 mock 与 API fallback 同步实现 `approvalWorkbench`，避免后端未升级时界面缺域。
3. 前端 validator 增加审批工作台 shape、状态绑定、危险引用和旧版补全校验。
4. 审批中心页面使用企业 Vue2 控制台布局展示审批队列、Grant 影响、审计轨迹和处置红线。
5. 补充后端契约、前端契约和云端对抗 Review 规则。

## 关键约束

- 工作台为只读治理摘要，不执行批准、拒绝、撤销或 Grant 签发。
- Grant 必须绑定原始审批编号、策略版本、资源范围、授权时限和审计编号。
- 申请人不得作为唯一审批人批准自己的高风险动作。
- 补充材料只展示摘要和审计引用，不展示原文、PR 正文或下载链接。
